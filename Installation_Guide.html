CARL Installation Guide

Classification AI-Accessible Research Laboratory — Beta v1

Overview

CARL is a desktop application for taxonomists. This guide covers installing CARL from source using a Python virtual environment. No prior Python experience is required beyond running a single install script.

Installation creates a self-contained venv/ folder inside the CARL directory. It does not modify your system Python or install anything globally.

Requirements

RequirementDetails
Operating system Windows 10/11, macOS 12+, or Linux (Ubuntu 20.04+)
Python 3.11 recommended (3.10 or later required). Download from python.org.
Disk space ~3 GB (dominated by PyTorch, needed for the nomenclatural-codes chatbot)
Internet connection Required during installation (package downloads) and for API-hosted language models and biodiversity database queries
Windows users: when installing Python, tick "Add Python to PATH" on the first installer screen. Without this the install script cannot find Python.
macOS users: install Python from python.org rather than Homebrew to ensure tkinter is included. If you use Homebrew Python, run brew install python-tk afterwards.

Step 1 — Download CARL

Download the CARL source code from GitHub. Choose the method that suits you:

Option A — Download ZIP (no Git required)

  1. Go to https://github.com/allengrodrigo/CARL_beta_v1
  2. Click Code → Download ZIP
  3. Extract the ZIP to a folder of your choice (e.g. C:\CARL on Windows or ~/CARL on macOS/Linux)

Option B — Clone with Git

git clone https://github.com/allengrodrigo/CARL_beta_v1.git
cd CARL_beta_v1

Step 2 — Run the Install Script

Open a terminal (or File Explorer on Windows) in the CARL folder and run the appropriate script for your platform.

Windows install.bat

Double-click install.bat in File Explorer, or from Command Prompt:

install.bat

macOS Linux install.sh

chmod +x install.sh
./install.sh

The script will:

  1. Verify your Python version
  2. Create a virtual environment in venv/
  3. Install all required Python packages (see requirements.txt)
  4. Create a launcher — run_carl.bat (Windows) or run_carl.sh (macOS/Linux)
Installation time. The first run downloads PyTorch (~200 MB) and sentence-transformers models. On a typical broadband connection this takes 3–10 minutes. Subsequent installs are much faster as packages are cached.

Step 3 — Start CARL

After installation, start CARL using the launcher created by the install script:

PlatformCommand / action
Windows Double-click run_carl.bat
macOS Linux ./run_carl.sh

CARL will open with the File panel → Nomenclature tab. Open the included example file NEXUS_CARL.nex via File → Open to explore a working dataset.

Step 4 — Set Up a Language Model

CARL's analyses (Descriptions, Comparisons, Keys) work without a language model. A language model is required only for the AI-assisted output modes and the Carl chatbot. Two options are supported:

Option A — API-hosted model (recommended for first-time users)

CARL supports Groq, OpenAI, Anthropic, Google, HuggingFace, and OpenRouter. Groq offers a generous free tier and is the recommended starting point.

  1. Create a free account at console.groq.com
  2. Generate an API key in your account dashboard
  3. In CARL: go to Settings → LM Settings, select Groq as the provider, and paste your key into the API Key field
  4. Click a model name in the model list to populate the model fields, or type a model name directly (e.g. llama-3.3-70b-versatile)

Option B — Local model via Ollama (no internet required after setup)

  1. Download and install Ollama from ollama.com
  2. Pull a model, e.g.: 
    ollama pull llama3.2:3b
  3. In CARL: go to Settings → LM Settings, select Ollama (local) as the provider, and enter the model name (e.g. llama3.2:3b)
API keys are stored locally in taxongpt_settings.json in the CARL folder and are never transmitted to any service other than the provider you configure.

Step 5 — Configure Databases (optional)

CARL can retrieve records from external biodiversity databases automatically. Default settings work for most users. To customise which databases are queried, go to Settings → Databases.

Two databases require additional setup:

DatabaseWhat's needed
WSC — World Spider Catalog A free API key from wsc.nmbe.ch. Enter it in Settings → Databases alongside the provider row.
BHL — Biodiversity Heritage Library A free API key from biodiversitylibrary.org. Enter it in Settings → LM Settings → BHL API Key.

All other databases (GBIF, CoL, ITIS, WoRMS, ZooBank, CrossRef, NCBI, Plazi, Wikipedia, Wikidata, BacDive, IPNI) are freely accessible without a key.

Troubleshooting

Install script says "Python not found"

Python is not on your PATH. On Windows, re-run the Python installer and tick "Add Python to PATH". On macOS/Linux, ensure python3 is available: which python3.

faiss-cpu fails to install

Some platforms require a specific pre-built wheel. Try:

pip install faiss-cpu --no-build-isolation

If that fails, install Anaconda or Miniconda and use: conda install -c conda-forge faiss-cpu

tkinter is not available (macOS)

Install Python from python.org (the official installer includes tkinter). Alternatively: brew install python-tk@3.11

CARL opens but the window is blank or very small

On high-DPI displays (4K, Retina), Tkinter scaling may need adjustment. On Windows, right-click run_carl.bat → Properties → Compatibility → Change high DPI settings → Override scaling behaviour → Application.

The chatbot cannot find nomenclatural-code indices

The RAG indices for ICZN, ICN, ICNP, and ICVCN must be built separately. Contact the CARL authors to obtain pre-built index files, or ask about building them from source.
